# Product design

## Core experience

PRAJNA behaves like a search workspace rather than a chat box.

- Search bar supports normal language.
- Lens chips communicate behavior clearly: Quick, Deep, Compare, Code, News.
- Result view separates answer, trust, sources, and framework activity.
- Sources are first-class objects, not footnotes hidden at the bottom.
- Mobile uses the same mental model with a compact stacked layout.

## Original product concepts

### Mission Board
A future collaboration surface where a complex question can become a mission with subtasks, artifacts, owners, evidence, and status.

### Evidence Graph
Claims can be linked to multiple sources. Contradictions become visible instead of silently averaged away.

### Source Passport
Every source can carry domain, freshness, type, retrieval provider, and optional reputation signals.

### Lens Composer
Advanced users can eventually save custom lenses such as “SEC filings only”, “peer-reviewed biomedical”, or “code + docs, no forums”.

### Continuity Capsule
A privacy-scoped session summary can move between web, phone, and desktop without requiring the raw conversation to be copied into every prompt.
