- Search and model adapters
- Evidence scoring + de-duplication

## Phase 3

- collaborative workspaces
- enterprise connectors
- camera/visual search

- end-to-end evaluation harness and golden query sets

## Phase 4
- agent marketplace with permission manifests
- claim-level contradiction detection
- personalized reranking that is transparent and reversible
- research report generation with reproducible evidence bundles
